# dotDoctor

내 건강 기록을 읽고 가정의학과 의사처럼 매주 소견을 써 주는 안드로이드 앱.

- **검사**: 혈액검사 추이 HTML 파일 가져오기(휴대폰 안에서 처리), 직접 입력, 항목별 추이 그래프
- **헬스 커넥트**: 삼성헬스의 걸음·수면·심박·체중·혈압·혈당·산소포화도·운동 (읽기 전용)
- **기록**: 증상·진료·메모, 약 복용 변화
- **주간 리포트**: 지난주 요약을 미리 보기로 확인 → '보내기'를 누르면 Claude API가 소견을 씀

## 개인정보 원칙 (절대)

- 이 저장소에는 **어떤 개인 건강 정보도 올리지 않는다.** 코드만 있다. 자세한 규칙은 [CLAUDE.md](CLAUDE.md).
- 기록은 휴대폰 앱 안에만 저장되고, 구글 백업에서도 빠진다.
- 휴대폰 밖으로 나가는 것은 사용자가 확인하고 보낸 주간 요약뿐 (이름·생년월일·병원 이름 제외).
- API 키는 앱에서 입력하고 안드로이드 키스토어로 암호화해 휴대폰에만 둔다.
- 모든 빌드 전에 `tools/privacy_check.sh`가 데이터 파일·키·주민번호 모양을 검사한다.

## 빌드

GitHub Actions에서 빌드한다. Dot·DotTrace와 같은 서명 키를 쓰려면 저장소 Secret `DEBUG_KEYSTORE_BASE64`를 등록한다.
Actions 탭 → Build APK → Run workflow 를 누르면 Releases에 APK가 올라간다.

> 이 앱은 의사의 진료를 대신하지 않는다.
